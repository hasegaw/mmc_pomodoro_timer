# pomodoro timer

## 概要

- 映像配信向け pomodoro timer
- Windows 環境で動作するネイティブ exe ファイルとして作成する

### ウインドウ仕様

- OBS からのウインドウ選択が容易になるよう、ウインドウ名・可能であればウインドウクラス名を Pomodoro Timer もしくはそれに類するものに固定する。
- OBSのウインドウキャプチャを可能にするため、ウインドウタイトルバーは表示しない。ウインドウのドラッグは背景部分のドラッグを使用する。
- クライアントアスペクト比 1:1、 500px x 500px とする
    - 縮小表示モードの場合は 250px x 250px とする
- Windows の画面設定にて文字サイズを標準から変更している場合にUIボタンやタイマーの文字レンダリングが収まるよう、必要時にはフォントサイズを小さくする。
- クライアント領域には以下を表示する
  - 現在の時間。タイマー表示 ([HH:]MM:SS) もしくはクリック操作により直接 [HH:]MM:SS を書き込み設定可能。
    - 編集モードではタイマー表示と同じフォント設定、入力コントロールの背景なしとし、編集モード移行時は現在のタイマー値が全選択された状態とする。
    - 入力された新時刻が HHMMSS もしくは MMSS 形式の入力だった場合は HH:MM:SS もしくは MM:SS として扱う。

### クライアント領域の背景
    - クライアント領域のデフォルト背景色は緑色 #00FF00 とする。
    - クライアント領域の背景画像 background.png/background.jpeg がある場合はそちらを優先する。短辺が500pxになるよリサイズして中央を切り抜く
    - ユーザはクライアント領域を OBS のウインドウキャプチャ機能で取得し、また特定色をクロマキー指定して利用する。

### 普段の表示内容

    - 残り時刻（もしくはその編集コントロール）: クライアント領域中央
    - リセット、スタート: クライアント領域下側寄せ

### タイマーのふるまい
    - デフォルトで 25m0s とする
    - リセットボタンを左クリックすると「スタートタイマー時刻」に戻る
    - スタートボタンを左クリックするとタイマーがカウントダウンされる。カウントダウン中はスタートボタンのかわりにストップボタンが現れる。
    - ストップボタンを左クリックするとタイマーのカウントダウンが停止する。停止中はスタートボタンが現れる。
    - タイマーが 0 秒になったら、timer.mp4、timer.mp3、timer.wav の順で見つかった通知音を再生する
    - クライアント領域を右クリックした場合はポップアップメニューを表示する。

### クライアント領域にカーソルがきたときのふるまい
    - クライアント領域にマウスカーソルが入ってきたときは、普段表示されていないリセット、スタート／ストップボタンを表示する
    - クライアント領域にカーソルがない場合はリセット、スタート／ストップボタンを表示しあい

### ポップアップメニュー
    - フォント: 時刻フォーマットに使用するフォント選択ダイアログを表示する
    - アラーム音を再生：通知音条件達成時、実際に通知音を再生するかどうかをEnable/Disableトグル切り替え。設定がない場合はEnableとして扱う。現在の状態にあわせてチェックを付ける。
    - 最前面に表示：Enable/Disableトグル切り替え。設定がない場合はDisableとして扱う。現在の状態にあわせてチェックを付ける。
    - 縮小表示：Enable/Disableトグル切り替え。設定がない場合はDisableとして扱う。現在の状態にあわせてチェックを付ける。

    - 終了: アプリを終了する

### 設定値の永続化

実行ファイルと同じディレクトリの pomodoro.ini ファイルに下記の設定値を永続化する。

- アプリのウインドウ位置
- スタートタイマー時刻: デフォルト 25m0s とする。ユーザーが数値入力した [HH:]MM:SS で上書きする。
- フォント情報
- 通知音の有効・無効
- 最前面に表示の有効・無効
- 縮小表示モードの有効・無効

### Stream Deck 対応

- 重複起動制御を行う。
- コマンドラインで /start /stop /click /reset /set {TIME_STR} を受け付ける。 /click は start/stop トグル操作。
    - すでに起動済みのプロセスがない場合は「タイマーが起動していません」ダイアログメッセージを表示して終了する。
    - /set のパラメータ {TIME_STR} はUI入力が受け付ける時刻フォーマットとして解釈する。書式エラーの場合は「時間フォーマットが正しくありません」ダイアログを表示して終了する。
    - /set は他の操作 /start, /stop, /reset と同時に指定できる。 /start /set は時刻設定+稼働状態に移行。 /stop or /reset + /set は停止状態に移行 + 時刻設定とする。
    - すでに起動済みのプロセスがある場合は IPC にてUI操作を代替する。制御メッセージの送信方法は適切なものを選ぶ。

## timer.mp3

- 再生ファイルは timer.mp4 もしくは timer.mp3 もしくは timer.wav から探す。
- 実行ファイルと同じディレクトリに配置する。
- プップッ～ピピピピ というイメージの通知音を作成し mp3 で保存する。
- python, d:\bin\ffmpeg を使用可能


## background.png

- 実行ファイルと同じディレクトリに配置する。
- #00FF00 500px x 500px の画像を生成する。
